# 🎮 Tic-Tac-Toe – Classic Reinvented

Welcome to the **Tic-Tac-Toe** project! This isn't just another browser game; it's a handcrafted interactive experience. Built with a passion for clean code and smooth interactions, this project serves as a perfect portfolio piece. Whether you're a recruiter assessing my frontend skills, a fellow developer looking to learn, or a player seeking a quick, fun game—you're in the right place. We've taken a timeless classic and given it a modern, polished feel, proving that even simple concepts can be executed with mastery and flair.

## 🛠️ Tech Stack

This project relies on the pure, foundational technologies of the web. No frameworks, no libraries—just raw skill.

- **HTML5**: Semantic structure for accessibility and SEO.
- **CSS3**: Modern styling with variables, pseudo-selectors, fluid 2D transforms, and keyframe animations.
- **Vanilla JavaScript**: Clean, organized logic for the game state, DOM manipulation, and event handling.
- **Audio Files**: For that satisfying *click* and *win* feedback.

## 💡 Core Concepts

This project demonstrates a deep understanding of frontend development by implementing these key concepts:

- **Semantic HTML**: Used for better structure, accessibility, and meaning.
- **Advanced CSS Techniques**: Leveraged CSS variables for theming, pseudo-selectors for dynamic styling, and fluid 2D transforms & keyframe animations for a polished, interactive UI.
- **Robust Algorithmic Game Logic**: A pure JavaScript engine that handles all win conditions, turn-taking, and draw states.
- **Dynamic DOM State Management**: The UI updates in real-time to reflect the game's state without any external frameworks.
- **Event-Driven Architecture**: User interactions are handled efficiently to control the game flow.

## 🕹️ How to Play

Getting started is simple! You have two options:

1.  **Play Online**: Click the link below to play instantly in your browser.
    - **Live Demo**: [https://daniyal-dar.github.io/tic_tac_toe/](https://daniyal-dar.github.io/tic_tac_toe/)

2.  **Run Locally**:
    - Clone this repository: `git clone https://github.com/daniyal-dar/tic_tac_toe.git`
    - Open the project folder in your favorite code editor (like VS Code).
    - Use a live server extension (e.g., "Live Server" by Ritwick Dey) to launch the `index.html` file.

## 🖱️ Controls

The game is designed for simplicity and ease of use. You only need one thing:

- **Mouse Left Click**: Click on any empty square on the 3x3 grid to place your mark (either 'X' or 'O').
